# MetaLens AI — Repository Overview

Concise summary: Android app that connects to Meta smart glasses (Meta DAT SDK), streams camera video, performs picture analysis, and runs hands‑free voice conversations via OpenAI Realtime.

**Key Modules**
- **Android root**: android/ — Gradle Kotlin DSL, version catalog, wrapper.
- **App module**: android/app/ — main Android app and Compose UI.
- **Wearables integration**: android/app/src/main/java/com/metalens/app/wearables — device registration, permissions, `WearablesViewModel`.
- **Streaming**: android/app/src/main/java/com/metalens/app/stream — `StreamViewModel` handles `Wearables.startStreamSession` and frame decoding.
- **Conversation (voice)**: android/app/src/main/java/com/metalens/app/conversation — `AudioIoController` (Bluetooth SCO, mic/playback), `ConversationSession` (session lifecycle), `OpenAIRealtimeClient` (WebSocket to OpenAI Realtime).
- **Picture analysis**: android/app/src/main/java/com/metalens/app/pictureanalysis — `OpenAIImageAnalysisService` (Responses API single-shot HTTP analysis).
- **Settings & storage**: `AppSettings` and `history/` for pref storage and conversation persistence.

**Runtime facts (concise)**
- **Audio format**: PCM16 mono @ 24 kHz (client + OpenAI Realtime). Critical for interoperability.
- **Bluetooth audio routing**: Uses Bluetooth SCO (AudioIoController) to target glasses mic/speakers.
- **Server VAD**: Realtime session uses server-side VAD; client sends `response.create` on speech end.
- **Image analysis**: Uses OpenAI Responses API (HTTP); images sent as data URLs.
- **mwdat dependency**: `com.meta.wearable:mwdat-*` is pulled from GitHub Packages; Gradle requires `GITHUB_TOKEN` or `android/local.properties` entry `github_token`.

**Build & run (strict)**
- **Prerequisites**: Android Studio, Android SDK + Platform Tools, JDK 17, Git.
- **Secrets**: Create `android/local.properties` (not committed) with:

  github_token=YOUR_GITHUB_TOKEN
  OPENAI_API_KEY=your_openai_api_key

- **Build (recommended)**: Open `android/` in Android Studio, let Gradle sync, run on emulator/device.
- **CLI build** (Git Bash recommended):

```bash
cd android
./gradlew :app:assembleDebug
```

**Why builds fail (common)**
- Missing JDK (`java` not in PATH).
- Missing `github_token` → cannot fetch `mwdat` from GitHub Packages.
- Missing Android SDK or mismatched `JAVA_HOME`.
